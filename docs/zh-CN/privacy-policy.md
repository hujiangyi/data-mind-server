# DataMind 隐私协议

最后更新：2026 年 9 月 4 日

## 1. 隐私承诺

DataMind 不会保留或记录用户私有业务数据，请放心使用。

这里的“用户私有业务数据”包括通过 DataMind 访问的业务表内容、查询结果、
上传到业务数据源中的文件和企业内部业务信息。DataMind Cloud 不会把这些
内容写入用于长期保存的业务数据库，也不会将其作为用户画像、广告或其他
商业用途的数据进行记录。

## 2. 本地部署的数据边界

DataMind Go 安装在用户或企业自己控制的 Linux 服务器、Docker 环境或其他
部署环境中。为了提供管理和权限能力，服务可能在该部署环境本地保存：

- 数据源连接配置和必要的凭据；
- 数据源、数据库、表和字段的元数据；
- 本地用户、子账号、角色、权限组和数据权限；
- 为故障排查和安全治理所需的操作审计信息；
- 服务运行配置、迁移记录和必要的 Cloud API Key。

这些内容属于用户自己的部署数据，不会自动上传到 DataMind Cloud。用户应当
按照自己的安全制度保护服务器、备份、日志、数据库凭据和 Cloud API Key。

## 3. Cloud AI 请求

当用户启用 Cloud AI 能力时，DataMind Go 会按照用户发起的操作，将完成该
操作所必需的请求发送到 DataMind Cloud 和配置的 AI 上游服务。DataMind
Cloud 只为完成请求提供中转、鉴权、配额和运行服务，不以保存用户私有业务
数据为目的。

服务可能保留不包含业务内容的账号、Key、用量、请求状态和错误类型等运行
信息，用于鉴权、计费、限流、安全防护和故障排查。请求正文、查询结果和
业务字段值不应写入这些运行记录。

## 4. 账号和密钥

邮箱、Cloud 账号和 DataMind API Key 用于身份验证、服务授权和用量管理。
用户应当妥善保管登录密码、API Key、数据库密码和服务器访问权限，不要将
它们提交到公开仓库、Issue、聊天记录或公开日志中。

## 5. 第三方服务

如果用户配置了第三方数据库、邮件服务、AI 服务或支付服务，相关数据会
按照用户与该第三方之间的协议处理。用户应独立阅读并评估第三方服务的
隐私、安全和数据保留政策。

## 6. 重装和数据删除

更新安装会保留本地数据和配置。重新安装会删除本地 DataMind 数据和配置，
包括已经关联的数据源、分配的子账号、数据权限和本地审计数据；重装后需要
重新配置。服务器备份、Docker 卷、操作系统日志和第三方服务中的副本不会
由安装器自动删除，用户需要按照自己的保留策略另行处理。

## 7. 联系和变更

本协议会随产品隐私边界和数据处理方式变化而更新。重大变化会在公开文档
或对应 Release 说明中标注。使用 DataMind 即表示用户理解并接受本协议中
关于本地部署、Cloud AI 请求和第三方服务的边界。
