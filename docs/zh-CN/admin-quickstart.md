# DataMind 管理员快速开始

目标：只配置一次数据源连接，之后让 AI 负责了解数据结构和编排常规人员、权限与本人相关数据任务。

## 1. 配置连接

在数据源管理页面填写并测试：

```text
数据源类型：MySQL 或 PostgreSQL
服务器地址、端口、数据库账号、密码
网络和 TLS 要求
```

连接成功后，打开 **AI 管理**。不需要手动同步或填写数据库、表、字段。

## 2. 让 AI 先了解数据源

```text
了解现在已经配置的数据源，告诉我有哪些业务内容，哪些表适合做与用户本人相关的数据。
```

Agent 会展示已发现的数据源、业务主题、负责人字段候选和敏感字段提醒。它只读取元数据，不把业务行样本放进普通任务记忆。

## 3. 创建用户

```text
创建平台用户 zhangsan，真实姓名是张三，角色是普通用户。
```

核对账号和角色，确认执行。初始密码通过受信方式交给员工，不要写入对话。

## 4. 配置本人相关数据

```text
给张三配置刚才发现的订单数据，但只能看负责人是他本人身份的记录。
```

如果发现多个候选，页面会列出数据源、数据库和业务说明，直接选择正确的一项。不要自行把区域、部门或项目描述成数据范围。

## 5. 确认与验证

确认计划前检查：

```text
目标用户正确
目标表来自 AI 已发现的真实目录
策略是 OWNER / DIRECT / EQUALS
没有区域、部门、项目、任意 WHERE 或全表权限
身份匹配证据清楚
验证和回滚方式清楚
```

执行完成后，用目标用户账号实际查询，确认只能看到负责人身份匹配的记录。分析未完成或身份冲突时，系统应阻断普通用户查询。

## 6. 继续使用

```text
检查张三当前有效权限和数据源身份绑定状态。
```

```text
停用账号 temporary_user。
```

```text
查看有哪些任务需要人工复核。
```

完整规则见[管理员 AI-first 指南](admin-guide.md)。
